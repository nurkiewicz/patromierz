# Patromierz

Production: https://patromierz.nurkiewicz.com/

## Local development

Install Ruby and Bundler, then start the Jekyll site from the repository root:

```sh
make serve
```

Open http://127.0.0.1:4000/. Changes are rebuilt automatically.

To install dependencies separately, run `make install`. The host and port can
be overridden, for example: `make serve HOST=0.0.0.0 PORT=8080`.
